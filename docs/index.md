# 实验室技术知识库

这里沉淀实验室的基础知识、技术模块、学习路径、项目复现记录、技术经验和交接资料。目标是让新成员能循序学习，让项目成果可以复现，让后续成员能接着已有工作继续推进。

## 从哪里开始

- **新成员**：从[基础知识](知识体系/基础知识/index.md)与[学习课程](知识体系/学习课程/index.md)开始。
- **查一个技术**：浏览[技术模块](知识体系/技术模块/index.md)，先看适用环境和最小示例。
- **复现一个项目**：进入[项目实践](知识体系/项目实践/index.md)，按项目 README 操作并记录验证结果。
- **排查问题**：查阅[技术经验](知识体系/技术经验/index.md)，按现象与环境检索。
- **补充内容**：遵循[贡献指南](关于知识库/贡献指南.md)和[文档写入规范](关于知识库/实验室技术知识库文档写入规范.md)。

## 知识如何持续积累

本库采用 Karpathy 提出的 LLM Wiki 思路：原始资料单独保存，归纳后的知识页互相链接并回到来源；每次收录都更新索引和时间线。LLM 可协助整理，成员负责核对来源、环境与结论。

```text
原始资料 sources/ → 归纳互链 wiki/ → 学习与复现 docs/ → 新经验回流
```

当前目录先搭好骨架。尚无实验室项目资料，因此示例条目不冒充已完成的项目或实测结论。
