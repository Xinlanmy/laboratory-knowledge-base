# 实验室技术知识库｜全书总目录

这是整本书的目录站。各部门的章节正文保存在对应负责人的 GitHub 仓库；从目录点击条目即可前往原文。本仓库只维护总目录、跨仓库链接、来源关系和写作规范，不复制章节正文。

## 从哪里开始

- **按目录学习**：浏览[全书目录](知识体系/index.md)，从对应章节链接前往部门仓库。
- **复现一个项目**：从[项目实践](知识体系/项目实践/index.md)进入项目负责人维护的 README。
- **排查问题**：从[技术经验](知识体系/技术经验/index.md)进入部门仓库中的复盘记录。
- **补充内容**：遵循[贡献指南](关于知识库/贡献指南.md)和[文档写入规范](关于知识库/实验室技术知识库文档写入规范.md)。

## 目录如何持续积累

本库采用 Karpathy 提出的 LLM Wiki 思路维护持久、互链的目录索引：目录项链接回各部门仓库的原始章节；每次新增或调整都更新索引和时间线。LLM 可协助检查链接与目录关系，成员负责确认章节归属和来源。

```text
部门仓库中的章节正文 → 总目录 wiki/ → 点击进入原文学习与复现 → 目录记录更新
```

目前已确认纳入目录的部门包括机器狗、双足轮式机器人、ROS 小车、工业设计、机械臂和嵌入式开发。它们的仓库地址仍待提供；目录会在收到地址后登记链接，并确认各部门具体负责的知识分类。目录项在确认来源前会标为待登记，不会用占位章节冒充已有内容。
