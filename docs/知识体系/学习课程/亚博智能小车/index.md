>
> 状态：草稿（学习路线依据官方教程仓库目录设计，来源链接已核实）
> 维护日期：2026-10-09

## 课程定位

以亚博 ROSMASTER M3 PRO 小车为载体，从零基础走到具身智能实战的一条完整学习路径。官方教程仓库提供 23 类课程（230+ 篇 PDF），本指南不复制正文，只规定学习顺序、依赖关系与过关标准；每一步点击对应章节前往官方仓库阅读并实操。

硬件背景：ROS2 Humble 系统，麦克纳姆轮全向底盘，6DOF 机械臂，双 TOF 激光雷达，大白 DCW2 深度相机，主控四选一（树莓派 5 / Jetson NANO B01 / Orin NANO SUPER / Orin NX SUPER），内置 OpenClaw 大模型具身智能框架。

## 面向对象

完全没有学习过人工智能或具身智能的成员。默认会日常使用电脑，不要求编程基础（遇到不懂的命令随用随查）。

## 前置知识

无硬性前置。课程内部自带地基章节（Linux、主控、OpenCV），按本指南顺序学习即可。

## 学习目标

完成后应能独立做到：

1. 远程登录小车并完成系统级操作（烧录、SSH/VNC、文件传输）；
2. 用 ROS2 写出自己的节点和话题通信程序；
3. 独立完成 SLAM 建图 + Nav2 导航，跑通 YOLOv8 目标检测；
4. 用机械臂完成颜色分拣与 3D 抓取，理解 MoveIt2 仿真-实物联动；
5. 通过 OpenClaw 的 MCP 接口，让大模型直接指挥小车完成任务。

## 知识模块（学习顺序）

整体分两块：**阶段 0–4 造机器人的能力（身体），阶段 5–6 给车装 AI 大脑**。上一阶段过关再进入下一阶段。

## 实践内容

- **方法**：每章 = 读官方 PDF + 在车上跑通例程 + 自己改一个参数复现效果。改完能复现才算学会。
- **主线只有一条：22 Linux → 23 ROS2**。这是全书的分水岭，ROS2 没学扎实，后面所有章节只能「照着跑」，不能「改着用」。零基础成员最常卡在这里，宁可放慢也要过关。
- **顺序不能反**：阶段 0–4 是感知/导航/操作能力，阶段 5–6 才是 AI 大脑。不懂 ROS 就学 OpenClaw，等于不懂开车先学自动驾驶。
- **硬件安全**：机械臂与底盘实操前，清空工作半径内的人员与易碎物；小车行进测试先用手柄低速模式。
- 18/19/21 三门是工具课，按需穿插学习，不必集中完成。

## 项目衔接

- 学完阶段 3 可参与：巡检类项目（SLAM 建图导航）。
- 学完阶段 4 可参与：物流分拣、颜色分拣类项目（与实验室 ROS 物流分拣机器人项目衔接）。
- 学完阶段 6 可参与：具身智能应用开发（大模型 + MCP 控制机器人，与「智农卫士」空地协同巡检方向衔接）。
